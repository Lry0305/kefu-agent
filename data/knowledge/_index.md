# 客服知识库索引

> 知识库是客服回答问题的唯一依据。
> 没填好的内容别上线。

## 目录

| 目录 | 内容 |
|------|------|
| `01_product/` | 产品介绍、功能、适用场景 |
| `02_faq/` | 常见问题与解答 |
| `03_policy/` | 退款、隐私、服务条款 |
| `04_guides/` | 操作教程、入门指南 |
| `05_after_sales/` | 售后服务、退换货、投诉流程 |
| `06_pricing/` | 价格、套餐、优惠 |
| `07_contact/` | 联系方式、工作时间、各业务线对接 |
| `08_troubleshooting/` | 常见错误、故障排查 |
| `09_industry_terms/` | 行业术语、内部简称 |
| `10_scripts/` | 客服话术模板 |

## 填写顺序

建议按这个优先级填：

1. **必填**：01_product、02_faq、03_policy（上线前必须填完）
2. **推荐**：04_guides、05_after_sales、06_pricing、07_contact
3. **选填**：08_troubleshooting、09_industry_terms、10_scripts

## 注意事项

- 客服只从知识库取信息回答，知识库越全越不容易胡说
- 涉及钱和条款的，填完最好让同事核对一遍
- 有更新的内容，更新后跑一下 `--reindex`
